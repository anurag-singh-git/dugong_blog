## Fixes applied

### 1. Mixed British/American spelling (53 replacements, 12 files)

The site is written in American English throughout (behavior ×56, recognized ×3, fulfillment,
analyze). Three word families had drifted to British forms and were inconsistent with the
American forms already used elsewhere on the same site:

| Was | Now | Count |
|---|---|---|
| cancelled | canceled | 7 |
| cancelling | canceling | 18 |
| prioritised | prioritized | 2 |
| realisation(s) | realization(s) | 2 |

Before the fix the site carried both spellings side by side (canceled ×7 / cancelled ×7,
canceling ×5 / cancelling ×18). Prior QA passes missed this because the standing British-spelling
word list covered colour/fulfil/optimise/organise/analyse/behaviour/catalogue/licence/favourite/
utilise but not the -ise/-ised or doubled-L verb families. The word list used by this pass has
been widened to 26 patterns.

Files touched: 10 posts, plus feed.xml and llms.txt so every surface stays in sync. Occurrences
appeared in body prose, og:description, JSON-LD FAQ question and answer text, and the feed and
llms.txt deks. `cancellation` was deliberately left alone — the double-L is correct in American
English too. No URL, slug, filename, canonical or `@id` value was touched.

### 2. Footer collapses badly on phones (45 pages)

`.foot-cols` was a hard `grid-template-columns: repeat(3, 1fr)` with a `2rem` gap and no
responsive override on any page. At a 360px viewport the available track width works out to
roughly 85px per column after gutters and gaps, which squeezes labels like "Post-mortems" and
"Interviews" to the edge of their column and gives the footer a cramped, two-line-per-link look on
most phones. The `@media (max-width: 760px)` rule that already existed only collapsed the parent
`.foot-top`, never `.foot-cols` itself.

Added to all 45 rendered pages, immediately after the base rule:

```css
@media (max-width: 560px) { .foot-cols { grid-template-columns: repeat(2, 1fr); gap: 1.5rem 1.25rem; } }
@media (max-width: 340px) { .foot-cols { grid-template-columns: 1fr; } }
```

CSS brace balance re-verified on all 89 files after the edit.
