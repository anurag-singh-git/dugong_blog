had finished and shipped Nº 139; the first half of this pass was carried out
against the pre-publication tree, noticed the repository changing underneath

## Fixed

1. **The homepage skip link skipped nothing.** 103 pages point `.skip-link` at
   `#main`, the `<article role="main">` below the masthead. `index.html`
   pointed its own at `#view-home`, the wrapper that *contains* the ticker,
   the header and the nav, so the single control on the page whose purpose is
   to bypass the navigation returned the keyboard user to the top of the
   document. WCAG 2.4.1. The hero now carries `id="main"` and the link points
   at it; verified in a browser, where the first Tab plus Enter now lands
   focus at y=131, exactly the bottom edge of the nav, against y=0 before.

2. **404.html had no reduced-motion block.** The other 105 rendered pages
   shorten every animation and transition under
   `prefers-reduced-motion: reduce`. 404.html alone had none, so its link and
   summary transitions ran at full duration there and nowhere else. This is
   the third defect of the same shape on that page: markup shipped ahead of
   the stylesheet rule, after `.article-dek` on 10-21, `.short-answer` on
   10-31 and `:focus-visible` on 11-02. Verified under emulation: transition
   duration now 1e-05s with reduce, 0s without.

3. **Eight British spellings in a house that writes American ones.** The day's
   dispatch shipped `fulfilment`, against 1,222 uses of `fulfillment` and none
   of the British form anywhere else. The sweep that found it turned up seven
   more sitting in the three dispatches published since 10-31: four `colour`,
   one `behaviour`, one `judgement`, one `customise`, one `apologise`. Each
   had travelled into the md rendition, `llms.txt`, `llms-full.txt` and the
   feed along with its page, so eight typed words were 28 published ones. All
   28 corrected. Two spellings were deliberately left alone: `cancelled` is
   the house form, 260 uses to 11, and those 11 are Shopify's own trigger
   names ("Order canceled") quoted as the admin writes them; and the three
   `colour` hits in CSS comments are not reader-facing.

## Added to the checker

Three new invariants in `_tools/seo-check.py`, each with its row in
`_tools/README.md`, each tested in both directions before being kept:

* **house spelling**, over every rendered page's visible text plus every md
  rendition, `llms.txt`, `llms-full.txt` and `feed.xml`. `analyse` is off the
  table because the suffix pattern reads `analyses`, the plural of `analysis`,
  as a British verb; it fired on exactly that the first time it ran, and a
  check that cries wolf gets switched off.
* **the skip link's target opens after `</header>`**, which is the defect in
  item 1 stated as an invariant. A page with no header, meaning 404.html,
  whose first focusable element is already the content, has nothing to skip
  and is not required to carry the link.
* **every rendered page carries a reduced-motion block**, which is item 2.

## Open, not actioned

* **The live site is three dispatches and eleven days behind the repository.**
  blog.dugong.live still serves ISSUE Nº 136 / OCT 24 and 136 dispatches;
  the tree here is at Nº 139 / NOV 4 with 93 dispatch pages. The last commit
  is `1059055` on 2026-10-30, and the work of the 10-31, 11-02 and 11-04 runs
  sits uncommitted across 169 paths, including three dispatch pages that have
  never existed outside this machine. Nothing in this pass changes that:
  committing and pushing publishes content, which is a decision for a person,
  not for a QA run. Everything below the fold of this report is about files
  that readers cannot currently see.
* **The homepage puts `banner`, `navigation` and `contentinfo` inside
  `role="main"`.** `#view-home` carries the main role and wraps the ticker,
  the header, the nav and the footer. Assistive technology still exposes all
  four landmarks, so the practical cost is small, and the fix is not a
  one-attribute change: `.view.active.home > .hero > *` drives the hero
  entrance animation and the reveal script reads `.view.active .foot`, so
  either moving the header and footer out or wrapping the content in a
  `<main>` changes the box tree those selectors depend on. Worth doing
  deliberately, with the animations re-checked, rather than inside a QA pass.
* **23 paragraphs run past 170 words and 85 sentences past 70**, which is long
  on a 390px screen. Editorial judgment, not a defect; listed so the number is
  on the record if the house wants a ceiling.
* **External link liveness is unverified.** 236 distinct external URLs, mostly
  `help.shopify.com` and `shopify.dev`. Outbound HTTP is blocked for arbitrary
  hosts from both shells available to this run, so only a spot check was
  possible: `help.shopify.com/en/manual/shopify-flow`, the most-linked target
  at 50 uses, resolves to a live article. The rest remain unchecked.
